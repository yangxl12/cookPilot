# CookPilot Demo

基于 [REQUIREMENTS.md](./REQUIREMENTS.md) v0.3 实现的手机网页演示。使用 React、TypeScript、Vite 和 Lucide 图标，不需要后端或 API Key。电脑打开时保持最大 480px 的手机界面，没有额外的桌面端布局。

页面使用白底与绿色操作样式。首页支持输入菜名、几个食材或模糊想法，先在对话中推荐几道菜，选中后再获取完整指南：已有 AI 菜谱直接打开原版本，新菜谱模拟生成后自动入库。完全无关做菜的问题显示聊天回答。“我的指南”分为“AI 菜谱”和“菜谱大全”两个 tab，首页“菜谱大全”按钮直接打开第二个 tab。备菜和全部步骤集中在指南中，步骤卡片作为独立阅读模式。

## 运行

最方便的方式：**直接用浏览器打开根目录的 `demo.html`**。该文件已内嵌脚本、样式、字体和成品图片，无需安装依赖或启动服务。模型相关功能仍为模拟。每次生产构建都会重新生成此文件。

继续开发时：

```bash
npm install
npm run dev -- --port 5173
```

打开 http://localhost:5173。同一局域网的手机可以访问启动日志中的 Network 地址，需允许本机对应端口访问。

```bash
npm run build       # TypeScript 检查 + dist/ 生产构建
npm run preview     # 预览生产构建
npm test            # 端到端交互测试，自动启动或复用开发服务
```

测试使用本机安装的 Google Chrome，无需额外下载浏览器。

## 建议演示路线

1. 首页模型按钮右侧打开“通用设置”，输入忌口、口味，多选锅具并保存。
2. 输入“有番茄和鸡蛋”或“想吃点快手的”，等待推荐；选择标有“AI 菜谱 · 已有”的番茄炒蛋，直接使用原版本，不增加记录。已有版本沿用原用量、进度与复盘，不自动应用新输入条件。
3. 返回首页，输入“想做日式咖喱鸡，450克鸡肉”，点击“选这道 · 生成菜谱”；等待后自动打开指南，在“AI 菜谱”中可找到新记录。再输入同一道菜会改为使用已有菜谱。也可输入“月亮为什么会发光？”查看聊天分支。
4. 查看平铺的主料与调味表、器具、备菜和全部步骤；菜名旁的信息图标展开要点，底部可直接进入“成品检查”。菜谱大全仍支持选菜后直接进入指南。
5. 点击菜名右侧的“步骤卡片”，左右滑动切换，点击数字直达，长内容在卡片内上下滚动。
6. 启动当前步骤计时，再从计时面板添加第二个命名计时。尝试暂停、继续、取消和刷新页面。
7. 切换到第二步，从标题栏的“问问 AI”求助“锅里出水了”。先看建议，再确认更新，查看建议中的步骤变化。
8. 返回指南，进入“成品检查”，勾选成品状态，评分，写一条复盘并保存；菜谱已在生成时入库，这里保存的是本餐结果。
9. 在“我的指南”的“AI 菜谱”中搜索、查看已生成指南或再次制作；“菜谱大全”中搜索和分类浏览预先导入的菜谱。再次制作沿用保存版本并从头开始。
10. 在“我的厨房”里添加、编辑、切换、模拟测试和删除模型；导出数据并检查文件没有 API Key。
11. 在数据管理中清空数据，体验空状态；使用“恢复演示数据”恢复两份初始指南。

## 实际可用与模拟范围

**实际可用**：通用设置持久化、锅具多选、菜谱搜索与分类、主料用量适配、花生和小葱避让、其他已识别食材冲突提示、备菜勾选、步骤卡片触摸滑动/数字跳转/键盘切换、多个命名计时、暂停/继续/取消、页面内到点提示、刷新恢复、剩余步骤确认调整、版本记录、AI 菜谱搜索/删除、复盘、再次制作、模型配置增删改切换、JSON 导出和本地数据管理。

**模拟功能**：首页意图分析、推荐、聊天、AI 生成、烹饪问答和模型连接测试。六套预置指南是宫保鸡丁、番茄炒蛋、土豆炖牛肉、番茄罗勒意面、日式咖喱鸡和法式蘑菇煎蛋。候选按本地关键词排序，聊天使用固定示例回答；未识别的做菜需求显示示例推荐。忌口文本保留到指南条件中；本地示例只对已识别食材做避让或阻止生成，不提供任意食物限制的完整推理。已有菜谱若含当前忌口食材会阻止选择，其他推荐仍可用。没有任何真实模型网络调用；图片与字体均在本地。

首页推荐本身不会写入菜谱；只有选中的新菜谱生成成功后才写入。已有菜谱按固定菜品 ID 复用，不新增指南，不重置进度。离开页面会停止待处理的分析或生成。首页对话刷新后清空，生成结果仍保存在本机。正式实现的语义去重、保存时幂等与菜谱/制作记录拆分要求见需求文档 5.1.1 和第 10 节。

计时使用截止时间而不是依赖每秒累减，页面刷新后恢复；到点不会自动推进步骤。暂停的计时器也有全局入口。浏览器后台可能节流，到点会在页面恢复时重新计算，不保证后台或锁屏通知。

数据保存在当前来源的 `localStorage`，键为 `cookpilot.demo.v1`。指南记录来源，AI 生成结果归入“AI 菜谱”，从预置列表打开的指南不混入该 tab；读取旧数据时保留指南、进度和复盘，移除旧收藏字段。菜谱大全地址为 `#library/recipes`，旧 `#recipes` 入口自动兼容。API Key 默认隐藏，导出时移除 `key` 字段；本 Demo 不提供加密密钥库，演示配置请使用测试值。不同端口、浏览器和设备不共享数据。

## 主要文件

- `src/App.tsx`：页面、底部弹窗和交互流程。
- `src/discovery.ts`：首页假数据意图分析、推荐排序、已有菜谱匹配与聊天回复。
- `demo.html`：可直接用浏览器打开的单文件演示。
- `scripts/package-demo.mjs`：从生产构建打包单文件 Demo。
- `src/data.ts`：类型、六道示例菜、通用偏好、条件适配、存储与计时工具。
- `src/styles.css`：手机界面和视觉样式。
- `tests/demo.spec.ts`：核心用户流程的浏览器测试。
- `DEMO_ANALYSIS.md`：需求分析与 A01–A13 对应实现。
- `public/images/`：本地成品参考图片。
- `public/fonts/`：DM Sans 拉丁字形及 OFL 字体许可；中文使用设备系统字体。
