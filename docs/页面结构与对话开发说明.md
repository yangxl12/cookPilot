# 页面结构与对话开发说明

- 对应需求：REQUIREMENTS.md v0.5
- 更新日期：2026-10-12
- 范围：本地 Demo UI、假数据交互和正式实现的页面约定。

## 页面结构

取消全局底部三个 tabbar，首页标题栏固定在视口顶部，从左到右为菜单、CookPilot 品牌、新建对话、模型选择、通用设置。最大宽度仍为 480px，大屏居中；窄屏缩减品牌图标与模型名称占位，完整名称在模型选择弹窗查看。

菜单从左侧滑出，桌面端贴合手机框左边缘，宽度不超过 320px。菜单顺序为 AI 菜谱、菜谱大全、我的厨房、对话历史。开始做菜即首页，不作为菜单项；移除我的指南页面与分类 tab。只有首页提供菜单入口，两个菜谱页、厨房页和烹饪页均使用返回按钮，沿实际访问顺序逐级返回首页。浏览器前进、后退及刷新保留页面路径；直接打开子页面时提供返回首页的路径。点击导航或历史自动关闭；遮罩、关闭按钮、Escape 均可关闭，弹窗内限制焦点并隔离背景，关闭恢复菜单按钮焦点。对话历史按今天、昨天、近 7 天、近 30 天分组，长列表在抽屉内部滚动。

AI 菜谱（`#ai-recipes`）和菜谱大全（`#recipes`）保留原有内容与页面内搜索，旧 `#library` / `#library/recipes` 分别重定向到对应页面。烹饪页面的准备/步骤数字导航保留，具体规则见 [烹饪指南开发说明](./烹饪指南开发说明.md)。

## 全局搜索

菜单顶部关闭按钮左侧提供搜索按钮。点击打开搜索弹窗，自动聚焦输入框，覆盖三个来源：

- AI 菜谱：菜名、食材、备菜、步骤、制作条件、心得和版本调整内容。
- 菜谱大全：所有预置菜谱的完整正文。
- 对话历史：最近 30 天有效对话的标题、每一轮用户消息、AI 回复与推荐内容。

关键词忽略大小写，空格分隔的关键词同时匹配。结果按 AI 菜谱、菜谱大全、对话历史分组，展示数量与命中摘要，点击后直接打开指南或恢复完整对话。空关键词只展示搜索框，无结果统一提示一次。搜索和摘要排除宣传式副标题与旧推荐套话。关闭或 Escape 返回菜单，再次关闭菜单回到首页并恢复焦点。搜索结果区域独立滚动，搜索框保持可见；过期对话继续遵循原有清理规则。

## 首页的两种布局

| 状态 | 布局与操作 |
| --- | --- |
| 尚无消息 | 只展示“想做什么菜？”和输入框；移除标题下说明、快捷提示词和菜谱大全入口，标题栏缩至 64px，内容靠近上方并保留设备安全区 |
| 已发送或恢复历史 | 显示消息和推荐；输入区固定视口底部，标题栏固定顶部；预留上下空间与设备安全区，消息滚动时输入区保持位置 |
| 分析/生成 | 输入和选择按钮防重复提交；菜单和新建对话仍可用，切换后取消旧任务，禁止延迟入库或跳转 |
| 新建对话 | 保留旧历史，清空输入和当前对话标识，回到首屏；首次发送才创建历史记录 |
| 恢复历史 | 关闭抽屉、打开首页、恢复全部消息及推荐；后续消息追加到同一对话 |

推荐和聊天继续采用六套本地菜谱与固定回复。四段初始历史只展示示例消息，不关联或自动创建指南。聊天历史本身不代表菜谱入库，只有现有选菜生成流程才写入指南。

## 数据与保留规则

在 `cookpilot.demo.v1` 的 `State` 内新增：

```ts
type Conversation = {
  id: string;
  title: string;         // 首条提示词，最多 28 字
  createdAt: string;     // ISO 时间
  updatedAt: string;     // 最后一次发送时间，查看历史不更新
  turns: DiscoveryTurn[];
};
// State.conversations: Conversation[]
// State.activeConversationId: string | null
```

最近 30 天定义为 `updatedAt >= 当前时间 - 30×24 小时`。恰好 30 天保留，超出即删除整个对话及消息。启动读取时过滤，打开页面期间每分钟再次检查并写回存储；应用关闭时无后台任务，下次打开补清理。过期记录如果为当前对话，清除当前标识并回到首屏，不删除已生成指南、心得、模型或计时器。

列表按 `updatedAt` 倒序；继续发送更新其时间并置顶。刷新恢复当前对话及候选。如果刷新发生在分析期间，将未完成消息转为“分析已停止，可以重新发送这条消息”，不会恢复旧任务。新建或导航通过请求序号使旧回调失效，防止写入其他对话。

旧数据没有 `conversations` 时补四段相对当前时间的示例历史，当前对话为空；已有空数组不补示例，确保清除数据后刷新仍为空。恢复演示数据重置为四段历史与两份指南。导出包含有效对话历史，继续排除模型 API Key。

## 验收

- 首页独占侧边菜单入口，侧边菜单中只有 AI 菜谱、菜谱大全和我的厨房三个页面项；子页使用返回按钮，逐级回到首页。
- 抽屉中历史位于我的厨房之后；点击示例恢复；新建后旧对话仍可恢复并继续。
- 紧凑首屏、全局搜索与发送后固定输入布局均在 320px、390px 和桌面宽度检查；长消息可滚动到最后且不被遮挡。
- 搜索涵盖菜谱步骤、心得和非首轮对话，结果跳转、关闭、清空与无结果状态可用。
- 返回、浏览器前进后退、刷新和旧地址兼容两个独立菜谱页。
- 新建/导航取消分析或生成，不发生延迟跳转和跨对话消息写入。
- 恰好 30 天保留，超过边界在加载和页面运行期间从 localStorage 删除；当前对话超期回到首屏。
- 清除全部数据包含历史；恢复演示数据、导出和旧数据迁移符合上述约定。

自动化验证位于 `tests/navigation.spec.ts`，已有指南、计时、模型等流程继续由 `tests/demo.spec.ts` 回归。真实手机软键盘和后台行为仍需设备验证；本 Demo 不接入后端定时任务或真实 AI 服务。
