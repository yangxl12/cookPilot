整理日期：2026-10-10。中餐 100 道，国外菜 100 道；全文中文，国外菜保留常用原文名，便于继续检索。

本资料通过多站点网页检索整理，优先采用能看到食材、操作步骤的具体食谱，涵盖美食天下、The Woks of Life、Just One Cookbook、Maangchi、RecipeTin Eats、Good Food、Hot Thai Kitchen、Swasthi’s Recipes、Spanish Sabores、Food From Portugal、Little Spice Jar 等。每道菜附具体参考链接。

正文是面向家庭厨房的归纳与改写，食材用量经过重新配比，火候、时间为操作估计，并非来源的逐字译本；未逐道实做。部分中文页面直接读取受限，依据检索可见的食材及步骤内容整理。不同地区、作者与家庭存在不同做法，本文固定一种便于操作的版本；少油或简化改法在相应条目说明。

## 使用说明

- 份量：菜肴通常为 2—3 人共享一道菜，米面主食通常为 2 人；整鸡、大锅汤、饼点的实际产量见食材或步骤。汤羹可以分次食用。
- 计量：g 为克，ml 为毫升；1 标准茶匙约 5ml，1 标准汤匙约 15ml。用秤和量勺最方便。未写入食材的葱花、香菜、柠檬等装饰或配餐均为可选；煮面、焯水另需的水不计入食材用水。
- 调味：盐、生抽、蚝油、豆瓣酱、鱼露和咖喱块的咸度差异大，按标量先少放、尝味后调整。写明的炸油是锅中用量，并不表示全部食用；剩油先过滤、妥善处理。
- 时间：所列为家庭操作估计，另需泡发、腌制、冷藏的时间单独提示；具体以食材大小、锅具、火力和熟度为准。烤箱先预热，温度按常规上下火理解；使用热风时按设备说明调整。
- 特色材料：椰浆与椰子水不同，日式味噌与韩式大酱不同，生抽也不能原样替代鱼露或印尼甜酱油；可用的近似替代写在对应菜的要点中。
- 地区归类：按日常流行与家庭做法组织，不对菜品历史起源作排他判断。中餐里的罗宋汤采用中式家常版；国外的海南鸡饭按新加坡流行的鸡饭组合整理。

肉类时间不能代替熟度检查。用食品温度计测最厚处、避开骨头：禽肉与复热剩菜达到 **74℃**；牛猪羊肉馅达到 **71℃**；鱼达到 **63℃**。生熟食材分开处理，易腐食物在 2 小时内冷藏；天气炎热时应更快处理。参考：[FoodSafety.gov 最低安全中心温度表](https://www.foodsafety.gov/food-safety-charts/safe-minimum-internal-temperatures)、[CDC 家庭食品处理说明](https://www.cdc.gov/food-safety/prevention/)。

**食材与调料**：小麦薄饼4张、熟鸡肉150g、熟黑豆100g、彩椒100g、洋葱50g、奶酪150g；油15ml、孜然粉2g、盐1g。

**做法**：

1. 彩椒洋葱切丁，用5ml油炒熟，加孜然和盐。
2. 熟鸡肉撕丝，与沥干黑豆及炒菜混匀。
3. 薄饼一半铺奶酪和馅，再覆少量奶酪，对折。
4. 平底锅薄刷油，中小火每面煎2—3分钟。
5. 馅料热透、奶酪融化后切三角，配酸奶油或莎莎酱。

**要点**：使用已经熟制的肉和豆；不要把生肉直接包进去煎。

**参考来源**：[Crispy oven baked quesadillas - RecipeTin Eats](https://www.recipetineats.com/crispy-oven-baked-quesadillas/)。

#### F094 墨西哥鸡肉焗卷（Chicken enchiladas）

**用时**：50分钟。

**食材与调料**：薄饼6张、熟鸡肉300g、熟黑豆150g、洋葱100g、奶酪120g；油15ml、番茄泥400g、孜然粉3g、红椒粉4g、盐3g。

**做法**：

1. 油炒洋葱，加入番茄泥、香料及盐，小火煮10分钟成酱。
2. 一半酱与撕碎熟鸡肉、黑豆拌成馅。
3. 薄饼热软，包馅卷起，接口朝下排入烤盘。
4. 浇剩余酱，撒奶酪。
5. 190℃烤20—25分钟至中心热透、奶酪金黄。

**要点**：成品酱汁要足够覆盖饼面，避免烤得过干。

**参考来源**：[Chicken Enchiladas - RecipeTin Eats](https://www.recipetineats.com/chicken-enchiladas/)。

#### F095 沙克舒卡（Shakshuka）

**用时**：35分钟。

**食材与调料**：番茄罐头500g、鸡蛋4个、彩椒150g、洋葱100g、蒜3瓣；油20ml、孜然粉2g、红椒粉3g、盐3g。

**做法**：

1. 洋葱彩椒切丁，蒜切末。
2. 宽平底锅加油炒洋葱彩椒5分钟，加入蒜和香料。
3. 倒番茄压碎，加盐，小火炖10—15分钟至浓稠。
4. 用勺挖4个小窝，各打入1个鸡蛋。
5. 盖锅小火煮6—10分钟至蛋白蛋黄凝固，配面包。

**要点**：本文采用全熟蛋版；酱汁太干时先补少量水。

#### F096 鹰嘴豆泥（Hummus）

**用时**：15分钟。

**食材与调料**：沥干熟鹰嘴豆300g、芝麻酱60g、柠檬汁30ml、蒜1瓣；橄榄油20ml、盐2g、冰水60—100ml、孜然粉1g。

**做法**：

1. 熟豆冲洗沥干，想更细腻可搓去部分豆皮。
2. 搅拌机先打芝麻酱、柠檬汁、蒜及40ml冰水。
3. 加入鹰嘴豆、盐及孜然，持续搅打2—3分钟。
4. 分次加剩余冰水，打至细滑能轻易抹开。
5. 盛盘用勺划纹，淋橄榄油，配饼和蔬菜。

**要点**：使用熟豆；芝麻酱用无糖纯芝麻酱。

**参考来源**：[Hummus - RecipeTin Eats](https://www.recipetineats.com/hummus/)。

#### F097 黎巴嫩法图什沙拉（Fattoush）

**用时**：25分钟。

**食材与调料**：皮塔饼1张、番茄250g、黄瓜200g、生菜100g、萝卜80g、葱1根、欧芹和薄荷各10g；油30ml、柠檬汁25ml、漆树粉3g、盐2g。

**做法**：

1. 皮塔饼掰片，拌10ml油，180℃烤8—10分钟至脆。
2. 蔬菜洗净擦干，切易入口的块，香草切碎。
3. 余油、柠檬汁、漆树粉、盐混成汁。
4. 蔬菜和香草入碗，与料汁轻拌。
5. 临上桌加入脆饼，快速翻匀。

**要点**：买不到漆树粉可多加少许柠檬汁，但果酸香会不同。

**参考来源**：[Lebanese Fattoush Salad - RecipeTin Eats](https://www.recipetineats.com/lebanese-fattoush-salad/)。

#### F098 摩洛哥柠檬鸡塔吉锅（Moroccan chicken tagine）

**用时**：75分钟。

**食材与调料**：带骨鸡腿600g、洋葱250g、蒜3瓣、盐渍柠檬半个、橄榄80g；油25ml、姜粉2g、孜然粉2g、姜黄粉1g、盐1g、水300ml。

**做法**：

1. 鸡肉拌香料和少量盐，放10分钟；洋葱切丝，盐渍柠檬冲洗后切条。
2. 厚底带盖锅加油，煎鸡两面上色盛出。
3. 底油炒洋葱蒜5分钟，放鸡和水，盖锅小火炖35分钟。
4. 加盐渍柠檬和橄榄，再炖15分钟至鸡熟软。
5. 开盖略收汁，配古斯米或面包。

**要点**：普通厚底锅可替代塔吉锅；盐渍柠檬、橄榄都咸，少放盐。

**参考来源**：[Chicken Tagine - RecipeTin Eats](https://www.recipetineats.com/chicken-tagine/)。

#### F099 土耳其红扁豆汤（Turkish lentil soup）

**用时**：40分钟。

**食材与调料**：去皮红扁豆180g、洋葱100g、胡萝卜100g、土豆150g；油20ml、番茄酱15g、孜然粉2g、盐3g、水1.1L、柠檬半个。

**做法**：

1. 红扁豆淘洗，蔬菜切小丁。
2. 锅加油炒洋葱3分钟，放番茄酱炒1分钟。
3. 加胡萝卜、土豆、扁豆和水，煮开后小火煮25分钟。
4. 蔬菜豆粒软烂后，用手持搅拌器打细，加孜然和盐。
5. 再煮2分钟，食用时挤柠檬汁，可配面包。

**要点**：热汤搅打时防溅烫；太稠可补开水。

**参考来源**：[Turkish Red Lentil Soup (Mercimek Corbasi Recipe) | Little Spice Jar](https://www.littlespicejar.com/turkish-red-lentil-soup-mercimek-corbasi/)。

#### F100 中东鸡肉沙瓦玛（Chicken shawarma）

**用时**：40分钟，另腌1小时。

**食材与调料**：鸡腿肉450g、蒜3瓣；油25ml、柠檬汁25ml、孜然粉3g、芫荽籽粉3g、红椒粉3g、姜黄粉1g、肉桂粉0.5g、盐3g；酸奶100g、皮塔饼3张。

**做法**：

1. 蒜末、15ml油、柠檬汁及香料、盐混成腌汁。
2. 鸡腿厚处划开，拌腌汁冷藏至少1小时。
3. 平底锅加余油，中火每面煎5—7分钟，至中心74℃。
4. 静置5分钟，逆纹切条；酸奶可拌少量柠檬汁作蘸汁。
5. 用热皮塔饼包鸡肉及洗净沥干的黄瓜番茄，淋酸奶汁。

**要点**：这是平底锅家用版本，保留沙瓦玛香料组合。

**参考来源**：[Chicken Shawarma (Middle Eastern) - RecipeTin Eats](https://www.recipetineats.com/chicken-sharwama-middle-eastern/)。
