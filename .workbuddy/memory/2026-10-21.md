# 2026-10-21

## 步骤卡片：最后一步完成按钮 + 步骤条玻璃边光错位修复

- `Carousel.tsx` 新增 `onFinish` / `finishLabel`（默认「完成，返回首页」），最后一张卡片底部渲染 `primary wide card-next` 按钮 + Check 图标；`Cooking.tsx` 传 `onFinish={() => app.navigate({ page: 'home' })}`。
- **玻璃边光错位根因**：`.card-pagination` 自己是 `overflow-x: auto` 的滚动容器，`::before`（inset:0 的 1px 渐变边）会跟内容一起横向滚走，滚动后边光跑到中间、两端开口。同理 `button.offsetLeft - nav.offsetLeft` 算居中也不对（offsetLeft 参照 offsetParent 不是 nav）。
- 修法：`.card-pagination` 只做不滚动的玻璃外壳（`overflow: hidden` + 圆角裁切），新增 `.card-pagination-track` 承担 `overflow-x: auto` 与内边距，ref 挂到 track；居中改用 `getBoundingClientRect` 差值 `nav.scrollLeft + rect.left - navRect.left - (clientWidth - width)/2`，实测居中误差 <1px。
- 顺手加了两端淡出：滚动时给 track 写 `data-edge="l r"`（空格分隔，`~=` 按 token 匹配，写成 `"lr"` 匹配不到——踩过），CSS 用 `mask-image` 只在真正被裁的方向淡出 20px，静止态不会被削到按钮。
- 注意：`overflow` 滚动容器里 padding-left 会被一起滚走（Chrome），文字会切在圆角上，所以必须有这层 mask，否则看起来像裁歪。
- e2e 新增「最后一步可以直接完成并返回首页」；全量 `playwright test` 36 通过，`vitest` 85 通过。提交 `e8b3673`。
