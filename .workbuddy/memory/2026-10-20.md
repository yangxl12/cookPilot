# 2026-10-20

## UI 改版：液态玻璃（Liquid Glass）

- `src/shared/styles.css` 末尾新增「Liquid Glass 主题层」，组件选择器沿用原有结构，只替换材质/配色，未改信息架构与文案。
- 主色：焦糖暖橙 `--brand: #b25017`（暗色 `#f0a173`，按钮填充 `--brand-fill` 渐变，暗色下按钮用浅橙底 + 深字 `--on-brand`）。
- 画布：`--canvas-bg` 多层暖色径向光斑 + 线性渐变；`body` 与 `.app-surface` 都用 `background-attachment: fixed; background-size: cover`，保证桌面留白与推屏抽屉下背景一致且不透明。
- 玻璃材质：半透明填充（`--glass-1..4`）+ `blur(26px) saturate(180%)` + 1px 渐变边（`::before` + mask xor）+ 非均匀高光；正文卡片 `.step-card` 用 `--glass-4`（0.88~0.9）保可读性。
- 滚动加深：`App.tsx` 监听 window scroll，写 `html[data-scrolled]`，CSS 用 `--bar-bg / --bar-blur` 切换导航透明度与模糊。
- 已适配 `prefers-color-scheme: dark`、`prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-contrast: more`。
- **坑**：`content-visibility: auto` 在非纯色（渐变/fixed）背景下重绘，会把列表行画成白底块；已从 `.catalog-row/.saved-recipe/.search-result/.step-card` 移除，列表本来有分页兜底。
- 列表行 hover 不再用半透明底色（合成层同样会露白），改为标题变暖橙 + 箭头右移。
- `index.html` theme-color 改为亮/暗两套（`#fbf5ee` / `#130e0b`）。
