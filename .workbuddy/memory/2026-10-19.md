# 2026-10-19

## 首页输入框固定底部 + 输入法适配
- `src/shared/useVisualViewport.ts`：监听 `visualViewport`，把键盘高度写入 `--kb`、键盘态写入 `html[data-keyboard]`（>80px 才算键盘）；iOS 用 offsetTop 补偿，Android 由 `interactive-widget=resizes-content` 自行缩布局视口。
- 输入框改为常驻 `position: fixed; bottom: var(--kb)`，Home 用 `createPortal` 渲染到 `.app` 下的 `#composer-host`（必须在 `.app-surface` 之外，否则 transform 会把 fixed 变成相对定位）。
- `--composer-h` 由 ResizeObserver 写入 `:root`，`.home` 用它做底部留白；输入框随内容增高（44→132px）时会 `scrollBy` 保持贴底。
- 发送/聚焦时 `scrollIntoView` 的哨兵带 `scroll-margin-bottom` 避开输入框。

## 侧边栏改为推屏式抽屉
- `src/features/home/useSideDrawer.ts`：`--drawer-x` 直接写在 `.app` 上，页面、输入框、计时器同步位移；`data-dragging` 期间关掉 transition 做 1:1 跟手；松手按速度(0.32px/ms)或 40% 阈值吸附。
- 手势：关闭态仅左边缘 28px 起手，开启态任意位置左滑关闭；竖向意图不拦截。
- `data-drawer` 有 open/closing/closed 三态：closing 保留 transform 让关闭动画能跑完，380ms 后落到 closed 并把抽屉 `visibility:hidden` 移出无障碍树。
- 抽屉组件常驻但内容在 `sheet` 打开时卸载，避免和 Sheet 里的同名按钮在 role 查询里撞车（Playwright 的 getByRole 不认 inert）。
- `MenuSheet` 已删除，导航条目并入 `Drawer.tsx`，抽屉里额外放了最近对话列表。

## 经验
- `.app-surface` 上的 transform 会把内部 `position: fixed` 变成相对该元素定位，凡是 fixed 子元素（输入框、计时器）都必须挪到 transform 外面。

## 首页细节微调（b9cf913）
- `.home-welcome` 改 `align-items: center` + `text-align: center`，`.home-browse` 去掉 `margin:auto`，标题/副标题/入口整体水平居中。
- 抽屉手势起手区从「左边缘 0~28px」改成「24~72px」带状：最外侧 24px 留给 Android 系统返回手势（那段触摸页面根本收不到），同时把可起手范围放宽一丢丢，用户不用死抠边缘也能拉开菜单。
- `.prompt-input textarea` / `.question-composer textarea` 隐藏原生滚动条（`scrollbar-width: none` + `::-webkit-scrollbar { display: none }`）：textarea 高度是 JS 按 scrollHeight 设的小数像素，容易溢出行高导致按钮左边冒出一条灰色细竖线。
